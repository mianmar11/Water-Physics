Purpose
    Create a fishing rod mechanic where the fishing bobber could thrown and
    float on the water. 

Specification
    A fishing bobber can be thrown using right click and it will have physics 
    applied to it. When thrown, it will go vertically upwards, then drawn down 
    by the gravity. It then checks if it collides with any nearby water areas
    and determines its ability to float or not. If it is in the water area, 
    it will become Buoyant and float on top of the water. Once it reaches to 
    the top, it will use 'wave_y()' function from 'Node' class. 

Implementation
    The fishing bobber `Bobber()` does not use 'wave_y()' function from 'Node'
    class when it reaches to the surface, however; the velocity of the bobber 
    works by using Water Boundary Checks and decides if the bobber should fall 
    down as in free fall or float up as in buoyancy depending on whether it is 
    inside water or not.

Purpose
    Create a string and attach to the fishing bobber.

Specification
    When Bobber has been created, the string will also be created and it will 
    attach its end points to the mouse position and the Bobber's center position.
    The bobber might also be able to move towards the direction that it is being
    pulled.

Implementation
    Bobber may inherit 'Point' class for it to be able to move towards the 
    direction it is being pulled, or it may have its own function that allows the 
    bobber to move towards the direction it is being pulled. It will move when 
    the contraint has succeeded it's maximum thresold (original distance) from 
    the last point from the string and bobber. The 'Point' should drag the 
    'Bobber' object for it to move.
